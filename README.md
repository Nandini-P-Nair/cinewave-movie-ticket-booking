#  CineWave Movie Ticket Booking Management

## Project Overview

CineWave Entertainment manages movie ticket bookings across
multiple theatres and locations.

This project implements a Movie Ticket Booking Management
application using the Pega Platform.

The application automates the booking process from submitting
a movie ticket request to final booking confirmation.

## Technology Used

- Pega Platform
- Pega App Studio
- Pega Blueprint

## Case Type

Movie Ticket Request

## Case Lifecycle

1. Initial Stage
2. Availability
3. Approval
4. Booking Execution
